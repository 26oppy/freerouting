# Hebrew PCB Terminology Notes

This glossary records terminology choices used for the first Hebrew localization pass.

## Translation style

- Use established Hebrew technical words where they are common and clear.
- Keep widely used PCB loanwords as Hebrew transliterations when that is what engineers usually expect.
- Example: keep "Via" as "ויה" instead of forcing a less familiar pure-Hebrew alternative.

## Core terms

| PCB / Printed Circuit Board | מעגל מודפס / לוח מעגל מודפס | Standard Hebrew usage in technical articles and vendor docs. |
| Via | ויה | Common transliteration in Hebrew PCB content. |
| Trace / Track | מסלול | Natural Hebrew technical word in routing context. |
| Layer | שכבה | Standard technical term. |
| Net | רשת | Standard EDA term in Hebrew UI contexts. |
| Net Class | מחלקת רשת | Direct and understandable mapping. |
| Clearance | מרווח | Short, clear, and works well in UI labels. |
| Keepout | אזור חסימה | Common descriptive wording for restricted placement/routing zones. |
| Padstack | פדסטאק | Technical loanword; transliteration is clearer for advanced users. |
| Pin | פין | Standard transliteration used in electronics. |
| Package | מארז | Standard Hebrew electronics term. |
| Routing | ניתוב | Standard Hebrew technical term. |

## Sources consulted

- Hebrew PCB explainers and glossary-style pages found through web search (industry/vendor Hebrew content).

## Follow-up recommendation

As native Hebrew-speaking PCB engineers review the UI, refine terms per context (beginner-friendly vs. expert-focused screens), while keeping "ויה" and similar loanwords where they improve usability.
